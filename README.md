A simple software rendering library written in C.

Currently working for Cocoa MacOS and Ncurses rendering backends.

---

Building:

You can use cmake to build this project. Go into the build directory and write
```sh
cmake ..
```

This will build the Cocoa demo program.

You can use the shell script name 'build.sh' to build it.
